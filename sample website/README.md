# Awais BBQ — Dynamic Restaurant Website

A responsive, animated Pakistani BBQ & fast-food website with:
- Dynamic menu filtering
- Add-to-cart and persistent localStorage cart
- WhatsApp order builder
- Mobile responsive layout
- 3D-style hero BBQ presentation
- Food gallery
- Restaurant contact/location section

## Setup
Open `index.html` in a browser or deploy the folder to any static host.

## Important
Open `assets/app.js` and set `CONFIG.whatsappNumber` to the restaurant's WhatsApp number in international format without `+` or spaces. Example: `923001234567`.
